## Boundary

Ces fichiers ne définissent pas l'API, les endpoints, les modèles
Django, les webhooks ou la logique serveur.

L'objectif est de donner à Kombai une source de vérité pour :

-   la structure de SCHOOL ON
-   les parcours utilisateurs
-   l'architecture des écrans
-   le responsive
-   l'identité visuelle
-   les composants
-   les états UI

L'intégration API/backend est traitée séparément.
