# SCHOOL ON --- Iconography

## 1. Icon library

Utiliser **Lucide Icons** comme base cohérente pour l'interface React.

## 2. Style

-   simple
-   outline
-   lisible
-   peu décoratif

## 3. Sizes

-   16px : inline / compact
-   20px : controls
-   24px : navigation
-   32px+ : empty states / feature visuals

## 4. Rules

Une icône fonctionnelle doit avoir un sens clair.

Ne pas utiliser une icône seule lorsqu'elle peut être ambiguë : ajouter
un tooltip ou un label.

Les icônes ne remplacent pas les informations essentielles.

## 5. Accessibility

Les boutons icon-only doivent avoir un nom accessible.

Les icônes purement décoratives doivent être ignorées par les
technologies d'assistance.
