# SCHOOL ON --- Radius System

## 1. Philosophy

SCHOOL ON doit être moderne et accueillant sans devenir excessivement
"bubble UI".

## 2. Tokens

  Token             Valeur indicative Usage
  --------------- ------------------- -----------------------------
  `radius-sm`                     6px petits contrôles
  `radius-md`                    10px inputs, boutons secondaires
  `radius-lg`                    14px cards
  `radius-xl`                    18px grands blocs
  `radius-2xl`                   24px hero / feature blocks
  `radius-pill`                9999px badges / pills

## 3. Rules

-   Inputs : radius-md
-   Buttons : radius-md
-   Cards : radius-lg
-   Grandes surfaces : radius-xl / 2xl
-   Avatars : cercle
-   Tags : pill

Éviter de mettre `radius-2xl` sur tous les composants.
