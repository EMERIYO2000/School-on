# SCHOOL ON --- Spacing System

## 1. Base unit

Utiliser un système basé sur **4px**.

``` text
4   → micro spacing
8   → compact
12  → small
16  → standard
20  → comfortable
24  → component
32  → section
40  → large
48  → major
64  → page
80  → hero
96  → large section
```

## 2. Component spacing

Exemples :

-   label → input : 8px
-   input → input : 16px
-   card padding : 20--24px
-   section spacing : 32--64px
-   page section : 48--96px

## 3. Container

Le contenu desktop doit rester lisible et ne pas s'étirer indéfiniment.

Utiliser un conteneur central avec des marges latérales adaptatives.

## 4. Rule

Plus un élément est important, plus son espace autour doit permettre de
le distinguer.

L'espace blanc fait partie de la hiérarchie visuelle.
