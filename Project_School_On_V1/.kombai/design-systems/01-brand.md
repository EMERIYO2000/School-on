# SCHOOL ON --- Brand Design System

## 1. Brand essence

SCHOOL ON est une plateforme intelligente pour apprendre, enseigner et
s'entraider.

L'identité visuelle doit communiquer :

-   apprentissage
-   progression
-   confiance
-   humain
-   technologie
-   communauté
-   opportunité

## 2. Direction visuelle

Le design doit être :

-   moderne
-   chaleureux
-   clair
-   professionnel
-   accessible
-   technologique sans être froid

Éviter :

-   esthétique SaaS générique
-   interface entièrement bleue sans personnalité
-   surcharge de gradients
-   excès de glassmorphism
-   interfaces trop enfantines
-   cartes avec des ombres lourdes partout

## 3. Personality

### Do

-   utiliser des espaces généreux
-   créer une hiérarchie claire
-   donner une sensation de progression
-   utiliser des accents chaleureux
-   valoriser les personnes et le contenu

### Don't

-   transformer chaque élément en carte
-   multiplier les couleurs
-   utiliser des animations décoratives inutiles
-   cacher les actions principales

## 4. Voice translated into UI

Le produit doit donner une impression :

> "Je sais où je suis, je sais quoi faire et je peux progresser."

Les textes UI doivent être :

-   courts
-   directs
-   humains
-   rassurants
-   sans jargon technique

## 5. Imagery

Privilégier :

-   personnes réelles
-   apprentissage
-   collaboration
-   création
-   technologie dans un contexte humain

Éviter les visuels génériques de "business people" sans lien avec
l'éducation.

## 6. Logo

Le logo doit être utilisé avec suffisamment d'espace autour.

Ne pas :

-   déformer le logo
-   ajouter des effets
-   changer arbitrairement ses couleurs
-   placer le logo sur un fond illisible
