# SCHOOL ON --- Typography

## 1. Font

Police principale recommandée :

**Ubuntu**

Une seule famille typographique permet de garder l'interface cohérente
et performante.

## 2. Hierarchy

Token Taille indicative Usage

---

Display 48--56px Hero / marketing
H1 36--44px Titre principal
H2 28--32px Section
H3 22--24px Sous-section
Body Large 18px Introduction
Body 16px Texte courant
Body Small 14px Informations secondaires
Caption 12--13px Métadonnées
Label 13--14px Formulaires

Les tailles doivent être adaptées au responsive.

## 3. Weight

- 400 --- Regular
- 500 --- Medium
- 600 --- Semibold
- 700 --- Bold

Éviter l'utilisation excessive du 700.

## 4. Reading

- line-height généreux pour les textes longs
- paragraphes courts
- largeur de lecture limitée
- contraste élevé

## 5. Numbers

Les nombres importants peuvent utiliser un poids plus fort :

- progression
- score
- nombre de cours
- durée
- prix
- statistiques

## 6. Code

Pour le contenu de programmation, utiliser une police monospace
distincte.
